# Không gian văn hóa Hồ Chí Minh — React 3D V1

V1 gồm phòng 3D, nhân vật di chuyển bằng WASD/phím mũi tên, camera bám theo, khu ảnh, sách, màn hình tư liệu, cây, bàn và tủ trưng bày.

Bản V1 chưa kết nối Firebase. Bước sau sẽ thêm Firebase, ảnh/video thật, nội dung triển lãm và khu quản trị.

Không cần VS Code để đưa project lên GitHub: có thể upload các file này qua trình duyệt, sau đó bật GitHub Pages bằng GitHub Actions.
